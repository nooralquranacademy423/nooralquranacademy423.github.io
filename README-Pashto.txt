## 1) Website
`index.html` خلاص کړئ. دا د زده کوونکو لپاره اصلي پاڼه ده.

## 2) Admin
`admin.html` خلاص کړئ.

له Dashboard څخه:

- د کورس فیس لیکل
- Live Class لینک او Recorded Video لینک اضافه کول
- ثبت شوي زده کوونکي لیدل
- زده کوونکي Approved کول
- د زده کوونکو CSV فایل ډاونلوډ کول

## 3) مهم محدودیت
دا نسخه د Demo/Prototype لپاره ده او معلومات د همدې Browser په `localStorage` کې ساتي.
یعنې که دا Website آنلاین شي، د ټولو خلکو معلومات به په ګډه Database کې نه ساتل کېږي.
د حقیقي آنلاین استعمال لپاره باید Server + Database + Secure Login + Payment system جوړ شي.

## 4) د اصلي آنلاین نسخې راتلونکی پړاو
- حقیقي Database
- Student accounts/login
- Teacher/Admin accounts
- Secure password system
- Payment verification
- Live class management
- Recorded lessons with protected access
- Attendance
- Certificates (که اړتیا وي)
- Online hosting او domain
